# 标注与强调

所有标注都作为镜头的 `overlay` 放进 `TakeShot`，坐标用录屏像素（3024×1544），这样会跟着镜头一起移动和缩放。

## 组件（@oii/kit）

| 组件 | 用途 | 要点 |
|---|---|---|
| `GlowRect` | 流光圆角矩形 | 从左上角开始顺时针快速画（默认 7 帧），画完后有一道白色流光一直绕框转。`at` 是开始帧，`until` 结束（最后 5 帧淡出），`drawFrames={0}` 表示直接显示完整框（用于跨镜头延续） |
| `Ripple` | 点击涟漪 | 录屏里本来就有光标，只补一个涟漪 |
| `HighlightRing` | 手绘椭圆圈 + 标签 | 偏活泼的风格 |
| `Callout` | 贴在 UI 上的信息气泡 | 如“✓ 4 个样片已生成”。和贴纸二选一，不要同时说同一句 |
| `Sticker` | 综艺花字贴纸（画面坐标 1920×1080） | 弹入 + 轻晃 + 收尾缩小。粉底白字＝关键操作，黄/绿底＝结果。见下方“花字与贴纸” |
| `MemeTitle` | 顶部大号描边玩梗标题（多行依次弹出） | 痛点开场用 |
| `StepCaption` | 步骤卡片 | 用 `placement="top-left" bold`，小而醒目，不抢画面 |

## 流光框的尺寸与粗细（已验证的取值）

- 统一加粗：`<GlowRect stroke={10} … />`（kit 默认 7 偏细）。在视频里包一层 `const Glow = (p) => <GlowRect stroke={10} {...p} />`。
- **框要比目标大一圈**：小目标四周留 ≥ 20 录屏像素，圆角跟着变大。参考值（录屏像素，260% 特写下）：
  - 单个颜色圆点：112×106，r 48
  - 三个叠加圆点：216×110，r 50
  - 画布右上角颜色栏（三色）：192×102，r 51（要包住整组，别只框到一半）
  - 列表项一整行：450×84，r 20
  - toolbar 按钮：66×64，r 18
- 一个操作配一个框：点列表项时圈住那一行；产品自动聚焦到目标后，再圈住落点（如被定位到的图片）。
- 框的出现时机：光标移向目标的过程中画出（`at` 2–6 帧），点击后保留到结果出现；跨镜头延续用 `drawFrames={0}`。

## 花字与贴纸（Sticker）

两种颜色，一眼区分：
- **粉底白字 = 关键操作**，带指向 emoji：`👆 添加颜色标签入口`、`👈 批量添加颜色标签`、`👉 点颜色，找到同类素材`、`✏️ 颜色标签可重命名`。光标移向目标时出现，到点击/结果出现为止。
- **黄底或绿底 = 结果**：`✓ 已标记`、`添加多个颜色标签`、`一次标记 8 个 ✓`、`唰～全亮了 ✨`、`一键直达 ✨`、`📦 标记素材已打包 zip 下载`。**在结果出现的那一帧**弹出（逐帧确认，早了晚了都会被指出），放在结果旁边。

规则：
- 只放在“核心操作”和“看结果”的地方；过渡镜头、痛点镜头不加（痛点只用 MemeTitle）。
- 一个结果一张；贴纸 + 说明框不要重复同一句话。
- 位置避开左上角步骤卡片和正在操作的区域；字号 36–40，旋转 ±4–8°。
- 用产品里的原词（见 oii-video-new 第 4 节）。

## 量坐标（不要估）

1. 抽出这一刻的原始帧：`ffmpeg -ss <rec秒> -i public/rec/recC.mp4 -frames:v 1 f.png`
2. 裁出目标附近区域放大看，或者用 Python/PIL 求亮像素的边界：
   ```python
   from PIL import Image; import numpy as np
   a = np.asarray(Image.open("f.png").convert("L").crop((x0, y0, x1, y1)))
   ys, xs = np.where(a > 200); print(x0 + xs.min(), x0 + xs.max(), y0 + ys.min(), y0 + ys.max())
   ```
3. 框要比内容四周各多出约 20px 留白，并且**上下居中**于内容（之前被反馈过“偏高了”）。
4. 圆角 `r` 和产品 UI 的圆角保持一致（20–24 比较合适）。

## 规则（来自过往反馈）

- 只圈当前这一步真正要点的东西，但要圈完整：例如“样片模式”要连同右侧的开关一起圈。
- 画框要快、顺时针、一笔画完；出现时机是光标到达之前或者正在点击的时候。
- 一个画面里同时最多一个强调元素。
