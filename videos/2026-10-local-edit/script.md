> 类型：**B. 自媒体教程**｜平台：B 站、小红书、视频号、抖音｜画幅：横版 1440×1080（4:3）+ 竖版 1080×1920

## 0. 这版新增了什么

1. **7 段出镜**（开场 / 4 次章节衔接 / 结尾），每段 4–12s，合计约 42s；不出现 >15s 的纯口播
2. **转场动画体系**：以“手指一指 → 流光框 → 屏幕”为母题，和产品的涂抹 / 框选流光一致；不加“嗖”声
3. **按 B 站调研的节奏**重排：开场蒙太奇 → 口头禅 + 承诺 + 利益点 + 收藏 → 难度递进 + 编号 → 每步“需求 → 结果 → 一句逻辑” → 互动 + 签名

### 2.2 数字人人设 + 口头禅 + 出镜台词

**人设（我来设计，供你确认）**

| 项 | 设计 |
|---|---|
| 名字 | **AI 抽卡君**（已定）——一个抽卡抽到手软的“资深玩家”，今天来劝大家别抽了。名字本身自带反差梗 |
| 人设一句话 | 抽卡抽到手软、终于“退坑”的老玩家；吐槽一句、教一句、得意一句；男声，年轻、松弛 |
| 口吻 | 短句、口语、自嘲；不端着；不说“赋能 / 颠覆” |
| 开场口头禅（固定） | **「我是 AI 抽卡君。今天，不抽卡。」**（名字 + 反差，一句成梗） |
| 自我介绍 | 「专门替你们抽卡抽到手软的那个。」 |
| 收尾签名（固定） | **「想要，就得到。我是 AI 抽卡君，下期继续不抽卡。」** |
| 观众互动用语 | 「评论区交作业。」（比“留言”更像“学习”） |

**为什么这样设计**：名字叫“抽卡君”，开场却说“今天，不抽卡”，一句话完成自我介绍 + 本期承诺 + 反差梗；与标题「别抽卡了」同义，不增加记忆负担；收尾「下期继续不抽卡」形成固定签名，后续每期可复用。

**台词（TTS 稿；已代入人设）**

| # | 台词 |
|---|---|
| ① | 我是 AI 抽卡君，专门替你们抽卡抽到手软的那个。今天，不抽卡。这期我把 AI 局部编辑的 5 个步骤、4 个工具——涂抹、框选、引用、对比——全部整理好了。提示词和原图，都在置顶评论的文档里。先点个收藏，我们开始。 |
| ② | 先从最简单的开始：你涂哪儿，它改哪儿。 |
| ③ | 好，上点难度。一次要改好几处，怎么办？ |
| ④ | 再难一点：有时候，你自己都说不清想要什么。 |
| ⑤ | 然后，甲方来了。 |
| ⑥ | 最后一个，也是最离谱的。看好了，别眨眼。 |
| ⑦ | 说到底，AI 不缺手艺，缺的是你说清楚想要什么。今天这几个，都是涂一下、说一句。你最想改哪一处？评论区交作业。想要，就得到。我是 AI 抽卡君，下期继续不抽卡。 |

### 2.3 数字人制作要求（不实拍）

| 项目 | 要求 |
|---|---|
| 形象 | 半身（胸口以上），亲和、略带吐槽感的表情；服装避免与品牌粉色冲突；不与背景同色 |
| 背景 | **导出绿幕 / 透明通道**两个版本（便于抠像悬浮 + 竖版重排）；全屏出镜用纯色或轻渐变底，别放杂物 |
| 画幅 | 横版 4:3 与竖版 9:16 各导出一套（头顶留白 ≥ 15%，竖版人物居中偏下） |
| 口型 | 台词按 TTS 音频驱动口型；每段单独生成（7 段），避免长段漂移 |
| 动作 | 优先用数字人**自带**的手势库：指向 / 摊手 / 点头 / 看手机。**不依赖自定义手势**；画圈、递卡、抽牌这些，用**后期动画**叠加（人物只做通用的“指一下 / 抬手”） |
| 表情 | 基础：微笑、微皱眉（⑥ 前）、得意（⑦） |
| 时长 | 每段 4–12s；不连续超过 15s |
| 音频 | **男声 TTS**：年轻、松弛、略带吐槽，不播音腔；语速约 4.5 字/秒；“想要 / 得到”略加重音；-16 LUFS；出镜与屏幕配音同一音色 |
| 试片 | 先做 10s 试片：口型、手势、抠像边缘（头发）、竖版构图，确认后再批量 |

> 手势降级：若数字人工具不支持“指向”，转场 T2/T4 改为：人物只是微微侧身，**画面的流光框自行从屏幕边缘展开**（手指一指由后期动画完成，不依赖人物动作）。

### 2.4 画面版式

| 版式 | 横版 4:3 | 竖版 9:16 |
|---|---|---|
| 全屏半身（①⑥⑦） | 数字人居中，下方口播字幕 | 数字人占画面区 + 口令区；顶部 140px 空出 |
| 抠像悬浮（②③④⑤） | 人物在左 1/3，右侧是将出现的画面（预留位） | 人物在下方 1/2，上方放画面 |
| 口播字幕 | 屏幕下方，字号小于步骤字幕 | 口令区下方，≥ 54px，每行 ≤ 14 字 |

## 3. 转场动画（母题：手指一指 → 流光框 → 屏幕）

> 与产品里“涂抹 / 框选的流光框”同一视觉；章节卡沿用品牌包装；不加“嗖”声，用轻“叮 / 啪”或不加声。

| # | 转场 | 衔接 | 做法（Remotion 组件设想） | 时长 |
|---|---|---|---|---|
| T1 | **成片预览 → 出镜①** | 蒙太奇最后一帧停格 → 缩进为小窗 → 人物出现 | 画面缩成圆角矩形 → 位移到右上角（PiP）→ 人物全屏淡入 | 0.6s |
| T2 | **出镜① → 痛点** | 人物一指 → 画面 | **手指一指**：人物手指指向画面外，指尖处一个流光圆角框展开，内容（咖啡馆图）从框里长大 | 0.6s |
| T3 | **痛点 → 出镜②** | 抽卡画面定格，叉掉 | 画面压成一条细线，人物从线里“拉开”出现 | 0.5s |
| T4 | **出镜② → Step 1 章节卡** | 人物手画一个圈 | **手画圈**：手指在空中画圈 → 流光圈放大成黑底章节卡 | 0.6s |
| T5 | **章节卡 → 屏幕演示** | 黑底大字 2s → 渐出 | 章节卡缩成左上角小标签「Step 1」，一直留在左上，作进度 | 0.3s |
| T6 | **Step n → 下一个出镜（③④⑤）** | 结果停留 1.5–2s → 结果图压到人物手上（“递给人”）→ 人物接 | 结果图缩小 → 飞到人物旁变成“卡片”→ 人物指向下一个画面 | 0.7s |
| T7 | **Step 2 → Step 3（小技巧后）** | 商品图三张并排 | 三张叠成一叠，被人物“抽走”最上一张 | 0.6s |
| T8 | **Step 4 内的甲方气泡** | 微信气泡弹出，推走上一张封面 | 气泡从右下弹入 → 带着封面滑出 / 滑入 | 每轮 0.5s |
| T9 | **Step 4 → 出镜⑥** | 五张胶片叠成一条，被拉出画面 | 胶片横向滑出，人物靠近镜头 | 0.6s |
| T10 | **出镜⑥ → Step 5 章节卡** | “看好了，别眨眼” | 镜头快速推进到人物眼睛 → 一次眨眼 → 黑底章节卡 | 0.8s |
| T11 | **Step 5 内：12 帧翻页 → 宫格 → 三刀** | 全屏翻页 | 全屏 → 缩成 4×3 宫格 → 红框锁花束 → 收束回原图 | 各 0.6s |
| T12 | **结果集锦 → 出镜⑦** | 四个工具并排高亮 | 四格缩到屏幕上方，人物从下方升起 | 0.7s |
| T13 | **出镜⑦ → EndCenter 落版** | 人物说完签名 | 画面模糊压暗，居中大字 slogan（品牌 `EndCenter`） | 0.8s |

**节奏规则**：
- 任何转场不超过 0.8s；画面静止 ≤ 10s；每 5–10s 有一次画面变化（局部放大 / 标注 / 对比 / 切换）
- “手指一指”“手画圈”各只用 2–3 次，避免滥用；其余用硬切 + 章节卡
- 章节卡带“难度 ★”：Step 1 ★ / Step 2 ★★ / Step 3 ★★ / Step 4 ★★★ / Step 5 ★★★（视觉上给“一点点上难度”的指示）

## 5. 玩梗设计（规范：1–2 个，各给 3 个方向）

### 梗位 A · 开头痛点（`MemeTitle`，0:23–0:31）

抓狂瞬间：**只想改一根手指，AI 把整张图重来一遍。**

| 方向 | 句子 | 出处 / 说明 |
|---|---|---|
| 经典句式 | 「AI 生图，就像一盒巧克力——你永远不知道，下一张手有几根手指」 | 《阿甘正传》“人生就像一盒巧克力，你永远不知道下一块是什么味道”；无数字，不需标“示意” |
| 拟人吐槽 | 你说：改一下手指。AI：「好的，已为您重开人生。」 | “重开人生”（《人生重开模拟器》等的网络用语）；一改手指整张图重来，贴合 |
| 夸张对比 | 「为了改一根手指，我把一张图，抽成了一部连续剧。」 | 夸张；无数字，口播顺 |

推荐：**经典句式（巧克力）做 `MemeTitle` + 拟人吐槽（重开人生）做气泡**。另有“人设反差梗”：AI 抽卡君，说“今天，不抽卡”（出镜①），不计入玩梗名额。

### 梗位 B · Step 4 甲方改稿（出镜⑤ + 气泡）

| 方向 | 句子 | 出处 / 说明 |
|---|---|---|
| 经典梗 | 「这个标题，能再大一点吗？」……五轮之后：「我觉得，还是第一版好。」 | 甲方经典话术（“logo 再大一点”“最后还是第一版好”）；落点接产品特性：每一轮都是新图，原版都在 |
| 拟人吐槽 | 甲方：「要高级，但别太高级；要大气，但别太大。」 | “又要马儿跑，又要马儿不吃草”式 |
| 夸张对比 | 「甲方一句话，设计师改一宿；现在，涂一下。」 | 一句话 vs 一宿的对比 |

推荐：**经典梗**（“再大一点” → “还是第一版好”）；落点画面：一点就回到第一版，字幕「每一轮都是新图，原版都在」。

## 6. 强调计划（规范：每步一个操作强调 + 一个结果强调；贴纸 + 花字 ≤ 10）

| Step | 核心操作 | 核心结果 | 操作强调 | 结果强调 | 结果停留 |
|---|---|---|---|---|---|
| 1 涂抹 | 选中图 → 工具条「局部编辑」→「涂抹」涂卫衣 → 一句话 | 卫衣变奶油黄 | 流光框圈「局部编辑」+ 花字「👆 先点局部编辑」 | 贴纸「✓ 只换了卫衣」+ 推近 | 1.8s |
| 2 框选 | 切「框选」→ 框脸（编号 1）→「1: 表情改为…」；选中两张 →「对比」 | 脸变了，其他没动（对比视图滑条） | 流光框圈「框选」+ 花字「多处要改？用框选」；流光框圈「对比」+ 花字「拖框选中两张，点对比」 | 贴纸「✓ 只有脸变了」 | 1.8s |
| 3 引用 | 点「引用」→ 框选另一张图 → “智能识别图片内容” | 包出现在女生身上 | 流光框圈「引用」+ 花字「说不清？引用另一张图」 | 贴纸「✓ 同款同色」 | 1.8s |
| 4 多轮 | 每一轮在上一轮结果上继续「局部编辑」 | 五张胶片 | 花字「上一轮的结果，就是下一轮的起点」 | 贴纸「✓ 5 轮 · 0 次重抽」 | 2s |
| 5 压轴 | 回到原图，框脸，改十二次；选中原图 + 表情帧 →「对比」 | 12 帧翻页，花没变（滑条扫过花束） | 字幕「同一张图 · 只改脸」 | 贴纸「✓ 花没变」 | 2s |

**每个 Step 的“一句逻辑”**（B 站调研：需求 → 结果 → 一句背后的逻辑；放在 Step 结尾，花字或出镜接）：

| Step | 一句逻辑 |
|---|---|
| 1 | 涂在哪儿，改哪儿。 |
| 2 | 一个框，一句话。 |
| 3 | 说不清，就给它看。 |
| 4 | 每一轮，只改一处。 |
