## 0. 录制范围（2026-10-13 更新）

用户决定：**入口 / 输入提示词 / 涂抹 / 框选 / 引用 / 对比，每个小功能只录 1 个步骤演示**，其余用图片 + 剪辑代替。因此：G01（入口 + 提示词 + 涂抹）✅、G02（框选）✅、G05（对比）✅，G04（引用）待录；G03、H3 取消。录屏进度与关键时间点见 `brief.md`「录制进度」与 `public/rec/marks.json`。

## 1. 总思路（一句话）

**素材全部先就绪 → 只录“操作过程”（4 段录屏）→ 其余画面用静态结果图在 Remotion 里拼 → TTS 配音 → 一份分镜数据，渲染横版 + 竖版两个 Composition。**

为什么这样拆：
- 结果图（A01–A22 等）已经有了，**不需要再等生成**；录屏只负责“怎么点、怎么涂、怎么说”——这是教程的核心，且只有 4 段。
- 录屏里的“等生成”一律后期加速并只显示“生成中”；结果大图用素材图接上，保证画面稳定、构图统一。
- 横版 / 竖版共用同一份分镜数据（`storyboard.ts`），只换版式组件。

## 4. 录屏方案

### 4.1 “录制用画布”（推荐新建，不动已整理的画布）

目的：画布干净、每个镜头需要的节点就位、没有无关内容（旧测试节点、失败品、后台面板）。

| 节点（上传自 `public/media/`） | 位置（相对） | 用于 |
|---|---|---|
| A18 雏菊原图 | 中间主位 | G01、G02 |
| A08 模特底图 | 右侧 | G03 |
| A03 旅游照 + A06 相机包图 | 下方并排 | G04 |
| A01 咖啡馆底图 | 左侧 | H3 |
| A19 / A22 / E05（结果图，用于对比） | 雏菊原图右侧一排 | G05 对比（不需要生成） |
| A12 / A17（封面第一版 / 第五版） | 下方 | G05 对比 |

做法：用“上传”把这 5 张图放进新画布；**不放结果图**（结果图由后期用素材接）。每段录完，结果节点会派生出现，保持原图在原位。

### 4.2 录制参数

| 项 | 值 |
|---|---|
| 视口 | 1512×772（CSS），录屏 3024×1544，30fps |
| 命令 | `ffmpeg -f avfoundation -capture_cursor 0 -framerate 30 -pixel_format nv12 -i "2:none" -vf "crop=3024:1544:0:420" -c:v h264_videotoolbox -b:v 40M recX.mp4`（`2` 与 `420` 首次试录校准） |
| 输出 | `public/rec/G01.mp4` … `G04.mp4`（本地，不进 git） |
| 停止 | `pkill -INT -f "ffmpeg.*G0X.mp4"`，等 4s，`ffprobe` 校验；**不用 kill -9** |
| 光标 | 页面内演示光标，不录系统光标 |
| 节奏 | 每个动作之间留 0.5–1s 静止；等待生成让它录着，后期加速 |

### 4.3 逐段操作脚本

> 每步记录 `__demo.marks` 时间点，对齐录制起点后写进 `brief.md`。

**G01 · 涂抹（Step 1，约 60–90s 原始时长，成片约 20s）**
1. 镜头：整张画布，缓慢推近 A18（一次只往一个方向走）
2. 点击选中 A18（停 1s）→ 工具条出现「局部编辑」（停 0.7s）
3. 点「局部编辑」→ 等画面稳定（约 20–30s，录着，后期剪）
4. 确认默认「涂抹」→ 涂卫衣（一笔 1.2s，涂紧不蹭）
5. 点输入框 → 打字机（真实输入，约 3s）：`把涂抹的卫衣改成奶油黄色，花束保持不变`
6. 提交 → 录到出现“生成中”→ 等结果（录着）→ 结果出现，停 2s
7. （完整方案）重复 4–6：涂头顶：`给她戴上一顶米白色的针织贝雷帽`；涂纸袋：`把涂抹的白色纸袋去掉，补成干净的墙面`
8. 要避免：打开结果节点的提示词面板

**G02 · 框选（Step 2，成片约 8s）**
1. 回到 A18 → 「局部编辑」→ 等稳定
2. 点「框选」（**先确认模式已切**，必要时点两次）→ 拖框脸（编号 1 出现，停 1s）
3. 打字机：`1: 表情改为张大嘴大笑，露出牙齿，其余不变` → 提交 → 等结果，停 1.5s

**G03 · 3 处框选（Step 2 小技巧，成片约 14s）**
1. 选中 A08 → 「局部编辑」→ 等稳定 → 切「框选」
2. 依次框腰带（1）、纽扣（2）、领口（3），每框停 0.6s，「框选列表」显示 3 项
3. 打字机三行：`1: 把黑色腰带改成焦糖棕色皮腰带`、`2: 把深绿色纽扣改成金色金属纽扣`、`3: 给领口加一圈白色柔软的毛领` → 提交
4. （可选）不等结果，后期接 A09–A11

**G04 · 引用（Step 3，成片约 12s）**
1. 镜头：A03（旅游照）与 A06（相机包图）同屏
2. 选中 A03 → 「局部编辑」→ 等稳定 → 点「引用」
3. 在 A06 上框选包 → 点星标“智能识别图片内容”→ 框上方出现识别标签（可能先识别成“白色连衣裙女生”，因框偏大）→ **点标签展开下拉，展示三个选项：棕色斜挎相机包 / 白色吊带连衣裙 / 杂志·小册子**，停 1.5s → 选「棕色斜挎相机包」（提示词里出现 [棕色相机包] chip）。注意：框要尽量只框住包，下拉才会包含相机包选项；下拉在标签正下方，点标签右侧小箭头
4. 回到 A03，涂抹位置（肩 / 腰侧）→ 输入：`斜挎在这位女生身上` → 提交 → 等结果，停 2s

**G05 · 对比（Step 2 / Step 4 / Step 5 共用，**不触发生成**，成片约 7s × 3）**
1. 在画布空白处**按住鼠标拖框，把要对比的两张图框进去**（拖选；原图与结果相邻摆放，方便一框两张）→ 工具条变为 **打组 / AI 剪辑 / 排序 / 对比 / 标签 / 下载**
   - 注意：这是**画布层的拖框多选**，不是局部编辑里的「框选」模式；画面花字写“拖框选中两张”以免混淆
2. 鼠标移到「对比」（悬停提示“对比”，停 0.6s）→ 点击 → 进入全屏对比视图（A | B，中间滑条）
3. 拖动滑条：从左缓慢扫到右（约 3s），停在脸上 1s；再回扫（可选）
4. 点右上 **×** 关闭
5. 三个取景：① 雏菊原图 vs 大笑（Step 2）；② 封面第一版 vs 第五版（Step 4，需要录制画布里有这两张）；③ 雏菊原图 vs 惊讶（Step 5）
6. 注意：A / B 哪张在左，取决于选中顺序（待试片确认）；原图应在 A（左）

**H3 · 涂手指（钩子，成片约 5s；可只录 UI）**
1. A01 → 「局部编辑」→ 窄涂杯子右侧多出的手指
2. 打字机：`擦除杯子右侧多出来的手指，补成毛衣和背景` → 提交（或不提交，后期接 A02）

## 5. 合成工程（Remotion，`videos/2026-10-local-edit/src/`）

| 项 | 做法 |
|---|---|
| Composition | 当前模板 `1920×1080`，改为 **`Landscape` 1440×1080** 和 **`Portrait` 1080×1920**，30fps，3:30 = 6300 帧 |
| 数据 | `src/data/storyboard.ts`（镜头数组：`id / start / dur / src / overlays / vo`），**与 `storyboard.md` 一一对应**；`manifest.json` 提供素材路径与尺寸 |
| 录屏接入 | 复用 `@oii/kit` 的 `Take / RecSequence / buildTake`（一镜到底剪辑、加速等待段、FreezePatch 遮盖） |
| 花字 / 贴纸 / 流光 | 复用 `@oii/kit` 的 `Sticker`、`highlight`（流光框）；打字机、气泡、章节卡先写在视频 `src/` |
| 出镜占位 | `OCPlaceholder`（黑底 + 标签「AI 抽卡君」+ 大字台词）；数字人后期替换，镜头时长不变 |
| 转场 | 章节卡、硬切、结果递入（先做 T4/T6/T8，其余硬切），不加“嗖” |
| 竖版 | 同一 `storyboard.ts`，`Portrait` 用分区版式（画面区 / 口令区 / 对比区），录屏二次裁切 |
| 音频 | TTS 母版 + BGM（口播下压）+ 点击 / “叮”；响度 -16 LUFS |
| 渲染 | `pnpm --filter local-edit render` 预览；正式 `release` |

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 录屏“首击被吞”，模式没切 | 每次先点一次、截图确认模式，再动手；录前预演一遍 |
| 画面 20–30s 才稳定，录屏变长 | 全部后期剪；重点保证稳定后再动 |
| 打字机内容与实际提示词不一致 | 展示文本由我生成并真实输入（G01–G04），不另编 |
| 12 帧漂移 2.4–5.6 | 对位 + 整体滤镜；口播只说“花没变” |
| 录屏里露出提示词面板 | 选中结果节点后先收起；或镜头推到结果图 |
| 画布自动聚焦抢镜头 | 录前关闭，录完恢复并告知 |
| 竖版放大录屏糊 | 3024×1544 原始分辨率足够 2× 放大；仍需检查 |
