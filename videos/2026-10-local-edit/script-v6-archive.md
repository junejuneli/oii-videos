## 一、主线

**一句话**：AI 生图最气人的是——整张图都很完美，就那一处不对。以前只能抽卡；现在哪儿不对涂哪儿，想要什么，直接说，就得到。

**情绪线**：气（抽卡）→ 爽（想要→得到连发）→ 服（进阶：电商 / 改稿 / 引用）→ 震（12 帧翻页，花没变）→ 悟（说清楚就够了）

**账号气质**（不靠设定，靠几个稳定的小习惯）：
- **吐槽式口吻**：像一个被 AI 气过很多次的朋友，吐槽一句、教一句、得意一句；不端着，不说“赋能 / 颠覆”
- **固定句式**：「想要 ___」→「得到 ___」。每个案例都这么收
- **固定转场「翻牌」**：每个案例结束时，“想要”卡片翻面变成“得到”卡片（结果图），再翻回下一个“想要”——一个动作，既是转场也是节奏点（详见第七节）
- **固定小贴纸**：左上角只有一个很小的「想要 → 得到」图标，不做系列计数、不做角色

## 三、观众与口吻

- 受众：会用 AI 画图、被「抽卡」折磨过、想要“可控”的人；不是专业设计师
- 口吻：短句、口语、自带吐槽；每句能直接做字幕
- 禁忌：不说“一个像素都没变”“完美”“百分百”；只说「基本保持 / 花没变 / 只有这里变了」；不展示失败（海报鞋子被重画等）

## 七、转场与账号辨识度

**主转场：翻牌（想要 ↔ 得到）**

- 每个案例以一张「想要 ___」卡片开始；操作完成后，卡片翻面成「得到 ___」（结果图）；翻回时顺势变成下一个案例的「想要」卡片。
- 声音：翻牌“啪”+ 结果出现“叮”。同一个音，全片复用，形成记忆点。
- 卡片样式：圆角矩形（与产品的涂抹流光框一致），大字，颜色用 OiiOii 品牌色。

| 位置 | 转场 | 说明 |
|---|---|---|
| 钩子 → 承诺 | 抽卡画面“翻”成 8 张想要卡片 | 把“抽卡”换成“想要→得到” |
| 案例 → 案例 | 翻牌 | 主转场 |
| 段 1 → 段 2 | 关卡牌「进阶 · 三式」（缩放 + 震 6 帧） | 1.5s |
| 模特 → 封面 | 老板的微信气泡弹出，推走模特图 → 封面（甲方气泡续上） | 梗即转场 |
| 封面 → 引用 | 五张封面叠成胶片抽出 | 0.8s |
| 段 2 → 压轴 | 关卡牌「最后一个」，节拍器音效起 | 1.5s |
| 翻页 → 三刀 | 12 格宫格收束回原图 | 0.8s |
| 压轴 → 收尾 | 画面压黑，大字浮出 | 0.8s |

**账号层面的稳定元素**（后续每期可复用，不做设定）：翻牌转场 + 同一个音；「想要 → 得到」收句；一种吐槽式口吻；统一的字幕样式和封面版式。

## 八、主题深化的三层（口播里已埋）

1. **操作层**：涂在哪，改哪；说一句就够。
2. **心智层**：图不需要一次完美——大方向交给生成，细节交给局部编辑；不再抽卡。
3. **价值层**：拉开差距的不是“会不会抽卡”，而是**说清楚你想要什么**。这是片子最后要留下的东西。

## 九、Tips 文档（简介 / 置顶评论）

| 案例 | Tips |
|---|---|
| 去路人 | 涂抹略大于路人，补全更自然；“擦除”一句话就够 |
| 去手指 / 去多余物 | 提示词对准“真实的毛病”：哪里多了什么；涂得越贴近，其余越稳 |
| 换颜色 | 颜色说具体（酒红 > 红）；涂紧，别蹭到旁边（小腿） |
| 加东西 | 说材质 + 颜色 + 款式（米白色针织贝雷帽） |
| 多处修改 | 用框选，按编号写：1: … 2: … |
| 改稿多轮 | 每一轮在上一轮基础上改；一次只改一处 |
| 引用 | 说不清就“引用”另一张图里的东西 |
| 通用 | 模型选 Pro 更稳（更贵）；图越“平光、背景简单”，其余越稳；每次进入局部编辑，等画面稳定再点 |
