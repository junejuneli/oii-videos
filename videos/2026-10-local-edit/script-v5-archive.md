## 一、一句话与主线

**一句话**：AI 生图最气人的是——整张图都很完美，就那一处不对。以前你只能抽卡；现在涂哪改哪，想要什么，直接说，就得到。

**情绪线**：气（抽卡）→ 爽（想要→得到连发）→ 服（进阶三式：电商 / 改稿 / 引用）→ 震（12 帧翻页，花没变）→ 悟（说清楚就够了）

**反复出现的两个口头禅**（做成花字，节奏锚点）：
- 「想要 ___」→「得到 ___」：每个小案例都用同一句式
- 「涂哪改哪」：落在每一段结尾的操作上，最后一镜是 slogan

## 二、系列设定：《人类驯服 AI》

**一句话**：AI 很野，但它听得懂人话——每期驯服它的一个“野性”。第 01 期驯服的是：**不听话的局部**（一改就乱、抽卡、听不懂）。

## 九、主题深化的三层（口播里已埋）

1. **操作层**：涂在哪，改哪；说一句就够。
2. **心智层**：图不需要一次完美——大方向交给生成，细节交给局部编辑；不再抽卡。
3. **价值层**：未来拉开差距的不是“会不会抽卡”，而是**说清楚你想要什么**。这是视频最后一句要留下的东西。

## 十、Tips 文档（简介 / 置顶评论）

| 案例 | Tips |
|---|---|
| 去路人 | 涂抹略大于路人，补全更自然；“擦除”一句话就够 |

| 引用 | 说不清就“引用”另一张图里的东西 |

## 十一、竖版 9:16（1080×1920，抖音 / 视频号 / 小红书）

**原则**：同一份配音和剪辑节奏，**重排版而不是裁切**。竖版时长压到 2:15–2:30（快打五连每格 4s、封面五轮缩到 14s、去掉收尾口播第二句）。

### 版面分区（1080×1920）

| 区 | 范围（y） | 放什么 |
|---|---|---|
| 顶部安全区 | 0–140 | 系列角标「驯服 AI · 01」+ 驯服计数（左上），平台 UI 会遮挡，别放关键信息 |
| **画面区** | 140–950 | 4:3 画面（1080×810）：原图 / 录屏热区放大 / 结果图 |
| **口令区** | 950–1350 | 打字机口令（大字，单行不超过 14 个汉字）；“想要”→“得到”字幕 |
| 对比区 | 1350–1650 | 前后对比（上下堆叠）/ 12 帧小宫格 / 步骤标签 |
| 底部安全区 | 1650–1920 | 平台 UI（点赞、简介），**不放字幕**；右侧 140px 留空 |

### 各段竖版处理

| 段 | 竖版做法 |
|---|---|
| 钩子 / 抽卡 | 老虎机动画占画面区，下方大字“抽卡”逐次放大 |
| 去路人 | 录屏**放大到工具条 + 输入框 + 画面**，不要整屏缩小；结果用上下对比（上：想要，下：得到） |
| 快打五连 | 一格一屏：上图“想要”，下图“得到”，口令在中间一行 |
| 模特 3 步 | 画面区放模特全身，右侧三个小框标出腰带 / 扣子 / 领口，口令区三行逐步出现 |
| 封面五轮 | **直接全屏 3:4 封面**（竖版最适合），下方甲方气泡一轮轮弹出；五次改动用角标 1→5 |
| 引用 | 左右 → 上下：上图相机包，下图目标图，中间一根“缰绳”线 |
| 12 帧翻页 | 画面区翻页；对比区放 12 格小宫格，随翻页点亮；花束用红框锁住 |
| 收尾 | 黑底大字居中，竖排更有力 |

### 竖版额外制作项

1. 录屏需要**二次裁切 + 运镜**（Remotion 里用 `buildTake` 做局部放大），而不是缩小整屏
2. 字幕：竖版字号 ≥ 54px，每行不超 14 字；横版字幕不可直接复用
3. 封面图：竖版封面单独做（左图“毛病”，右图“改完”，上下排）
4. 渲染：一份配音 + 两套合成（`Landscape` / `Portrait`），共用案例数据
