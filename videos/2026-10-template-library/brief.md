# 模板 功能介绍

- 创建：2026-10-14
- 状态：素材齐（录屏 recA/B/C/C2/D + 案例），待剪辑
- 成片：`out/template-library-vN.mp4`（本地，不进 git）
- 规格：1920×1080（16:9），30fps，目标约 55s；形式、包装沿用 `2026-10-grid-split`
- **无口播**：只用字幕 + 花字 + 贴纸 + 背景音乐（make-music.mjs 128 BPM）
- **不玩梗**（用户定）：开头用说明性短句
- **文案红线**：不写“新功能/全新/重磅”；不说省积分

## 一句话

**热门效果，一键同款。** 画布输入框里点「模板」，挑一个社区热门效果，换成自己的素材就能生成。

## 切入角度（2026-10-14 用户定：A + B）

主线：挑热门模板 → 换成自己的素材 → 出片。「我的模板」作为一段带过。

## 功能理解（2026-10-14 实测，画布 e26807c2）

| 能力 | 入口 / 表现 |
|---|---|
| 入口 | 选中图片/视频节点 → 下方提示词面板右上角「模板」（灯泡图标），旁边是「提示词助手」 |
| 面板 | 顶部 tab：全部模板 / 我的模板 / 最近使用；右上角「搜索模板」（会搜到提示词内容，不只标题）；打开时先显示「正在加载预设…」约 2–3s |
| 筛选 | 「所有行业」下拉：自媒体热点 / 电商带货 / 广告 / 短漫剧 / 游戏素材；标签：Vlog / 热点 / 口播 / 产品广告 / 角色表演；右侧 ⭐ 收藏 |
| 按节点分 | 图片节点里只出图片模板（封面是静图）；视频节点里只出视频模板（封面是视频，如乐事薯片包装变形动画、3D动漫第一人称互动、民国江南烟雨回眸） |
| **点卡片 = 立即套用** | 没有详情页/确认；面板关闭，**提示词 + 示例参考图 + 比例（+视频的模型/时长/分辨率）一起填好**，节点外形随比例变化（如 3:4 → 16:9 横板） |
| 图片模板实例 | 角色身份参考图表：一段约 1,500 字的专业长提示词（锁定五官、9 个角度、表情矩阵、身份锚点、色样），比例 16:9；参考图位是一张示例角色 |
| 视频模板实例 | 3D动漫第一人称互动：分镜级提示词（### Timestamped prompts 0–2s/2–5s/5–6.5s/6.5–7.5s/7.5–10s + Color/Lighting + Music/SFX），「角色1 图片1」等关键短语高亮成可识别的片段；自动切到 Metaso-H3 · 全能参考 · 9:16 · 10s · 768p（20 积分） |
| 换成自己的素材 | 删掉参考图位上的示例图（悬停出现 ×）→ 画布上复制自己的图（⌘C，提示「已复制到剪贴板」）→ 在提示词里 ⌘V，参考图换成自己的，并连出一条连线 |
| 生成 | 空节点直接在原节点生成；图片 4K 约 60–80s（预估 78s），视频预估 299s |
| 我的模板 | 「新建预设」：名称 + 上传封面 + 提示词（可添加参考图）→「创建预设」；用户已有：薯片人像广告、游戏概念板设计图鉴 |
| 最近使用 | 记录用过的模板 |
| 注意 | 选中已有节点再点模板，会**覆盖该节点的草稿提示词和参考图**（不会自动生成）；录制演示一律用新建的空节点 |
