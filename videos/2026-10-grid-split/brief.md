- 创建：2026-10-12
- 状态：✅ 成品 v5
- 成片：[1080p（Release）](https://github.com/junejuneli/oii-videos/releases/tag/grid-split-v5)；本地 `out/grid-split-v5.mp4`（母版）、`-share.mp4`（分享版）
- 规格：1920×1080（16:9），30fps，成片 46.6s；形式、节奏、标注方式沿用 `2026-10-color-tags`
- **无口播**：只用字幕 + 花字 + 贴纸 + 背景音乐
- **主打**：宫格图一键拆分 + 各种各样的玩法（B：玩法快切）+ 拆完接着做（C：图片高清）
- **文案红线**：不说“省积分”“更便宜”，不做积分对比；也不硬玩梗，用一眼看懂的说明性短句

## 一句话

**宫格图，一键拆开。** 一张图里画好一整套，选中点一下就拆成独立节点，每一张都能接着做。

## 功能理解（实测，测试画布 0755ca49）

| 能力 | 入口 / 表现 |
|---|---|
| 入口 | 选中图片节点 → toolbar「更多」→「宫格拆分」 |
| 预设 | 4宫格 (2×2) / 9宫格 (3×3) / 6宫格 (2×3) |
| 自定义 | 「自定义宫格」，行列最高支持 8×8 |
| 过程 | 顶部提示「正在拆分并上传 n/9」，约 5–10 秒；拆分本身不扣积分 |
| 结果 | 原图右侧按宫格自动排出子图节点，命名「原名 1…N」，**原图保留**；子图画幅与格子一致，无残边；每个子图都是独立节点 |
| 拆完继续 | 子图选中后「更多」→「图片高清」→ **2x（2 积分）/ 4x（4 积分）**；结果是新节点「高清 4x」（682×384 → 2728×1536），出现在原行右侧较远处，不紧挨原图 |
| 注意 | 选中节点后第一次点「更多」只高亮，第二次才展开；格子里烤进画面的文字会原样保留 |

## 切入角度（2026-10-12 用户定：B + C）

为什么在 OiiOii 里拆，而不是用切图工具：**一键拆，拆完就是画布节点，可以接着做。** 视频不讲“切图”，讲“玩法”和“拆完接着做”。

## 宫格图比例怎么选（2026-10-12 用户纠正）

**先想每个格子里的内容是横的还是竖的，再定整张图的比例。** N×N 拆分时每格与整图同比例，N≠M 时格子形状 = (W/M) : (H/N)。

| 格子里的内容 | 整张图比例 | 例子 |
|---|---|---|
| 横向：场景、镜头、风景、漫画横格 | **16:9** | 分镜九宫格（小猫旅行分镜） |
| 竖向：站立全身角色、人物立绘、手机竖屏内容 | **9:16** | 职业九宫格（站立的小猫） |
| 大头像、表情、图标（近似方形） | 16:9 + 8×5 之类，使每格近方形 | 狐耳表情 8×5（每格约 1.1:1） |

- 竖向内容放进 16:9 的格子会又宽又空，两侧留白多，拆出来的子图主体偏小；反之横向内容放进竖格会被挤。
- 4K 9:16 = 2160×3840，3×3 每格约 720×1280。
