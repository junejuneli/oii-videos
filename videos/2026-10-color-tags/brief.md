# OiiOii 颜色标签 功能介绍

- 创建：2026-10-09
- 状态：✅ 成品（v9，2026-10-09）
- 成片：`out/color-tags-v9.mp4`（母版）、`out/color-tags-v9-share.mp4`（分享版），本地，不进 git
- 规格：1920×1080，30fps，48s

## 功能理解

画布上的图片、视频、文本节点越来越多以后，很难快速分类和找回。颜色标签借鉴了 macOS Finder 的颜色标签，用颜色给节点分类：

| 能力 | 入口 / 表现 |
|---|---|
| 打标签 | 选中节点 → 节点 toolbar 最右侧的标签按钮 → 颜色面板（粉/黄/红/蓝/绿/紫，第一个“⊘”是清除） |
| 多标签 | 一个节点可以同时贴多个颜色，已选中的颜色带 ✓ |
| 标签显示 | 节点标题前出现彩色圆点，多个颜色时叠在一起 |
| 颜色栏 | 画布右上角（“发布”左侧）列出画布里用到的所有颜色 |
| 高亮 | 点击某个颜色，对应颜色的节点被高亮（带同色描边） |
| 资源列表 | 弹出面板列出这个颜色下的节点数和节点名称 |
| 聚焦 | 点击列表里的资源，画布镜头飞到对应节点 |
| 重命名 | 颜色名旁边的 ✎，可以把“绿色”改成有意义的名字，比如“定稿” |
| 批量打标签 | 框选/多选多个节点后，一次设置标签 |
| 批量 | 下载全部；取消标记（一次移除这个颜色的所有标记） |

**核心卖点**：像管理电脑文件一样管理画布素材，贴一下就分好类，点一下就找回来，并且可以批量下载。

## 视频脚本 v3

一句话：**给素材贴上颜色，分类、找回、批量下载，一步到位。**

风格沿用样片模式宣传片：真实画布操作的一镜到底录屏，演示光标 + 流光框标注 + 左下角步骤字幕，品牌封面和片尾。节奏比上一条更快，操作段加速到 2 倍左右，每段画面只保留关键动作。配音之后单独加，所以每段都给配音预留了时长，字幕也和配音的意思一一对应。

### 实测到的情况

- 框选：低缩放时直接拖拽就是框选，不会触发自动聚焦；多选 toolbar 是“打组 / 排序 / 标签 / 下载”，标签在第三个。
- 单击选中节点会自动聚焦（跳到约 82%）；生成类节点还会弹出提示词面板。录制时要临时关闭“画布设置 → 选中节点自动聚焦”，录完恢复。
- 低缩放时缩略图要几秒才加载出来，录前先把这条带来回扫一遍，让图片都缓存下来。
- 鼠标悬停时节点左上角会出现白色圆圈（多选勾选框），会让画面显得碎，光标移动路线尽量避开不相关的节点。
- 资源列表里显示的是节点标题：A2、B1 的照片标题都是“image”，文本节点显示“文本”，在列表和标签特写里都不好看。
- 画布上已有两个标签：红色 → 下方的视频“片段裁剪”，绿色 → 下方的一个文本节点。录前要清掉，否则会出现在列表里并影响节点数。

### 新发现

- 单选图片节点也会在下方弹出提示词面板（图片编辑），会盖住下一排；多选时没有这个面板。单个贴标签的镜头要把面板放到画面下沿之外，或者镜头只取节点 + toolbar。
- 多选时节点之间的连线（参考关系）会全部亮起来，画面比较乱；B2 的 MV 视频连线最多，A2 网格的连线较少。

- 改标题：双击标题进入编辑状态后，要先 ⌘A 再输入；如果还没进入编辑状态就按 ⌘A，会全选画布上的节点。

## 录制准备

- 画布（用户准备）：节点比较多（建议 15–30 个图片/视频/文本节点，内容统一，比如同一个故事的分镜、样片、成片），布局整齐，方便拉远后呈现“又多又乱”和“井井有条”两种状态。
- 录之前先清空已有的颜色标签，让打标签的过程从零开始。
- 第 3 段的框选：准备一组相邻的图片 + 视频 + 文本节点，可以一次框住。
- 预先想好每个颜色的语义，录制时重命名用：绿 = 定稿，黄 = 备选，红 = 待修改。
- 下载全部会真的触发下载，录制前要确认。

## 已确认

- 画布：用户单独准备，稍后提供工作区链接。
- 不展示“进入剪辑”。
- 已支持多选/框选批量设置标签，在第 3 段展示。
- 文本节点支持打标签，放进第 3 段的框选范围里。
- 节奏更快；配音后续单独加。
